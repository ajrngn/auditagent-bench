# Benchmark version changelog

Released versions at `gcs://<bucket>/benchmark/vN.N/` are **immutable**. A correction is a new version, never an edit.

`/cut-version` appends an entry here after the release gate passes. Every entry records what was measured, not what was intended.

## Entry format

```
## v0.1 — YYYY-MM-DD

**Items:** N total (A: n, B: n, C: n, D: n)
**Label sources:** disclosure n, human n, llm_draft_human_verified n
**Task C split:** n clean / n deficient
**Paraphrased subset:** n items
**Changed from previous:** —
**Reason:** —
```
